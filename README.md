# MangaSync Extensions

Repositorio filtrado de extensiones para Mihon.

Incluye únicamente estas 8 fuentes:

- YupManga
- TempleToons / Temple Scan
- Manga-Oni
- ZonaTMO
- MangaDex
- ImperioManhwa / Emperor Scan
- DragonTranslation
- ManhwaWeb

## Agregar a Mihon

Usá este archivo como URL del repositorio:

`https://raw.githubusercontent.com/Aguting13/MangaSync-Extensions/main/repo.json`

El repositorio se sincroniza automáticamente con el índice publicado de Keiyoushi y conserva solamente las 8 extensiones seleccionadas.

**ZonaTMO:** la extensión disponible actualmente en el índice upstream es `Zonatmo.to (unoriginal)`, con base `https://zonatmo.to`; no se fuerza `zonatmo.net` si la extensión publicada no lo soporta.
